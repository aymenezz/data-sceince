| العمود            | الوصف                                                          |
| ----------------- | -------------------------------------------------------------- |
| `CensusTract`     | رقم المنطقة الإحصائية (Tract).                                 |
| `State`           | اسم الولاية.                                                   |
| `County`          | اسم المقاطعة.                                                  |
| `TotalPop`        | عدد السكان الكلي في التعداد.                                   |
| `Men`             | عدد الذكور.                                                    |
| `Women`           | عدد الإناث.                                                    |
| `Hispanic`        | نسبة السكان من أصول إسبانية/لاتينية (%).                       |
| `White`           | نسبة السكان البيض (%).                                         |
| `Black`           | نسبة السكان السود (%).                                         |
| `Native`          | نسبة السكان من السكان الأصليين (Native American) (%).          |
| `Asian`           | نسبة السكان الآسيويين (%).                                     |
| `Pacific`         | نسبة السكان من جزر المحيط الهادئ (%).                          |
| `Citizen`         | عدد المواطنين الأمريكيين.                                      |
| `Income`          | متوسط دخل الأسرة السنوي (بالدولار).                            |
| `IncomeErr`       | هامش الخطأ في تقدير الدخل.                                     |
| `IncomePerCap`    | متوسط الدخل للفرد.                                             |
| `IncomePerCapErr` | هامش الخطأ في تقدير الدخل الفردي.                              |
| `Poverty`         | نسبة السكان تحت خط الفقر (%).                                  |
| `ChildPoverty`    | نسبة الأطفال تحت خط الفقر (%).                                 |
| `Professional`    | نسبة العاملين في الوظائف المهنية (%).                          |
| `Service`         | نسبة العاملين في خدمات مثل الرعاية أو المطاعم (%).             |
| `Office`          | نسبة العاملين في وظائف مكتبية (%).                             |
| `Construction`    | نسبة العاملين في البناء (%).                                   |
| `Production`      | نسبة العاملين في المصانع والإنتاج (%).                         |
| `Drive`           | نسبة من يذهبون للعمل بالسيارة (%).                             |
| `Carpool`         | نسبة من يشاركون السيارة مع غيرهم للعمل (%).                    |
| `Transit`         | نسبة من يستخدمون وسائل النقل العامة للعمل (%).                 |
| `Walk`            | نسبة من يذهبون للعمل مشيًا (%).                                |
| `OtherTransp`     | نسبة من يستخدمون وسائل أخرى (دراجات، دراجات نارية... إلخ) (%). |
| `WorkAtHome`      | نسبة من يعملون من المنزل (%).                                  |
| `MeanCommute`     | متوسط وقت التنقل إلى العمل (بالدقائق).                         |
| `Employed`        | عدد العاملين.                                                  |
| `PrivateWork`     | نسبة من يعملون في القطاع الخاص (%).                            |
| `PublicWork`      | نسبة من يعملون في القطاع العام/الحكومي (%).                    |
| `SelfEmployed`    | نسبة العاملين لحسابهم الخاص (%).                               |
| `FamilyWork`      | نسبة من يعملون في أعمال عائلية بدون أجر (%).                   |
| `Unemployment`    | نسبة البطالة (%).                                              |
